# 寻轨战队中期考核

## 电控部分
**功能描述**：基于 STM32F103C8T6 控制四个 TT 马达，结合麦克纳姆轮，实现小车的前进、后退、左右平移及原地旋转。
**思路**：
1. **驱动**：两块 DRV8833 分别驱动两个电机
2. **PWM**：电机需要 1kHz 的 PWM 频率。采用 TIM2（控制左侧两轮，PA0-PA3）和 TIM4（控制右侧两轮，PB6-PB9）。时钟树配置为 72MHz 系统主频，APB1/APB2 分频后，定时器时钟为 72MHz。通过设置 Prescaler=71, Period=999，恰好得到 1kHz 的 PWM。
3. **软件**：未使用 FreeRTOS。经测算，主干控制循环耗时极短，CPU 占用率低，使用循环架构足以保证 100Hz 的控制周期，同时能大幅降低新手期的栈溢出风险和调试难度。
4. **难点与解决**：新手首次焊接，防止马达堵转导致瞬间压降，在代码中对轮速进行了限幅处理。

1. 在Clion里面进行Debug，通过检测数组psx_buf的各项内存值判断程序是否有效
2. 初始得到的均为255，整成数字模式了，代码是用模拟模式实现的，$ 这垃圾手柄指示灯的问题 $
3. 然后在手柄通信函数那里打断点，事实查看验证了SPI通信的可行性
```c
// PS2 读取函数（ps2.c）
void PS2_ReadData(void) {
    CS_LOW();
    PS2_TransferByte(0x01);
    psx_buf[1] = PS2_TransferByte(0x42);  // 返回 0x73 表示红灯模式
    // ... 
    psx_buf[5] = PS2_TransferByte(0x00);  // 右摇杆 X
    psx_buf[7] = PS2_TransferByte(0x00);  // 左摇杆 X
    psx_buf[8] = PS2_TransferByte(0x00);  // 左摇杆 Y
    CS_HIGH();
}

// 摇杆数据解析（main.c）
if (psx_buf[1] != 0x73) return; // 必须是模拟模式
int lx = (int)psx_buf[7] - 127; // 映射至 -127 ~ 127
if (abs(lx) < 8) lx = 0;        // 死区处理，防止摇杆漂移
```
