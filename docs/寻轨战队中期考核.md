# 寻轨战队中期考核

## 电控部分
**功能描述**：基于 STM32F103C8T6 控制四个 TT 马达，结合麦克纳姆轮，实现小车的前进、后退、左右平移及原地旋转。
**开发历程与技术思考**：
1. **驱动选型**：单个 DRV8833 只能驱动两个电机，本方案需要驱动四个 TT 马达，因此选用两块 DRV8833 模块并联使用。
2. **PWM 资源分配**：电机需要 1kHz 的 PWM 频率。采用 TIM2（控制左侧两轮，PA0-PA3）和 TIM4（控制右侧两轮，PB6-PB9）。时钟树配置为 72MHz 系统主频，APB1/APB2 分频后，定时器时钟为 72MHz。通过设置 Prescaler=71, Period=999，恰好得到 1kHz 的 PWM。
3. **软件架构选型**：未使用 FreeRTOS。经测算，主干控制循环耗时极短，CPU 占用率低，使用裸机“超级循环”架构足以保证 100Hz 的控制周期，同时能大幅降低新手期的栈溢出风险和调试难度。
4. **遇到难点与解决**：新手首次焊接，杜邦线难以承受 TT 马达启动大电流。解决方案是将 TT 马达引线直接焊接到 DRV8833 排针上，并套热缩管绝缘；同时，防止马达堵转导致瞬间压降，在代码中对轮速进行了限幅处理。
