# 寻轨战队中期考核

## 电控部分 刘珈辰
**功能描述**：基于 STM32F103C8T6 控制四个 TT 马达，结合麦克纳姆轮，实现小车的前进、后退、左右平移及原地旋转。
**思路**：
1. **驱动**：两块 DRV8833 分别驱动两个电机
2. **PWM**：电机需要 1kHz 的 PWM 频率。采用 TIM2（控制左侧两轮，PA0-PA3）和 TIM4（控制右侧两轮，PB6-PB9）。时钟树配置为 72MHz 系统主频，APB1/APB2 分频后，定时器时钟为 72MHz。通过设置 Prescaler=71, Period=999，恰好得到 1kHz 的 PWM。
3. **软件**：未使用 FreeRTOS。经测算，主干控制循环耗时极短，CPU 占用率低，使用循环架构足以保证 100Hz 的控制周期，同时能大幅降低新手期的栈溢出风险和调试难度。
4. **难点与解决**：新手首次焊接，防止马达堵转导致瞬间压降，在代码中对轮速进行了限幅处理。

**舵机转动控制**
```c
// --- 舵机目标角度与当前角度（用于平滑追踪） ---
int target_mg996 = 90, current_mg996 = 90;
int target_sg90_1 = 90, current_sg90_1 = 90;
int target_sg90_2 = 90, current_sg90_2 = 90;

// --- 按键状态记录（边缘检测用） ---
uint8_t last_L1 = 1, last_R1 = 1, last_L2 = 1, last_R2 = 1;

void loop_servo_and_car(void) {
  if (psx_buf[1] != 0x73) return;

  // 1. 读取按键状态 (L1/R1/L2/R2)
  uint8_t L1 = (psx_buf[4] & 0x04) == 0 ? 1 : 0;
  uint8_t R1 = (psx_buf[4] & 0x08) == 0 ? 1 : 0;
  uint8_t L2 = (psx_buf[4] & 0x01) == 0 ? 1 : 0; 
  uint8_t R2 = (psx_buf[4] & 0x02) == 0 ? 1 : 0; 

  // 2. 读取摇杆（死区 25）
  int lx = (int)psx_buf[7] - 127; 
  int ly = (int)psx_buf[8] - 127; 
  int ry = (int)psx_buf[6] - 127; 
  if (abs(lx) < 25) lx = 0;
  if (abs(ly) < 25) ly = 0;
  if (abs(ry) < 25) ry = 0;

  // 3. 按键边缘检测：按下 L2/R2 直接设定目标角度为 90
  if (L2 == 1 && last_L2 == 0) { target_mg996 = 90; }
  if (R2 == 1 && last_R2 == 0) { target_sg90_1 = 90; target_sg90_2 = 90; }
  last_L1 = L1; last_R1 = R1; last_L2 = L2; last_R2 = R2;

  // 4. 摇杆控制：改变目标角度（增量控制）
  if (L1) {
      if (lx > 0) target_mg996 += 2;       
      else if (lx < 0) target_mg996 -= 2;  
      Motor_Stop(); // 控制舵机时底盘刹车
  } else if (R1) {
      if (ly > 0) target_sg90_1 += 2;
      else if (ly < 0) target_sg90_1 -= 2;
      if (ry > 0) target_sg90_2 += 2;
      else if (ry < 0) target_sg90_2 -= 2;
      Motor_Stop(); 
  } else {
      loop_ps2_car(); // 不按肩键时正常跑底盘
  }

  // 5. 安全限位保护 (限制在 20 ~ 160)
  if (target_mg996 > 160) target_mg996 = 160;
  if (target_mg996 < 20) target_mg996 = 20;
  if (target_sg90_1 > 160) target_sg90_1 = 160;
  if (target_sg90_1 < 20) target_sg90_1 = 20;
  if (target_sg90_2 > 160) target_sg90_2 = 160;
  if (target_sg90_2 < 20) target_sg90_2 = 20;

  // 6. 平滑追踪执行（每次靠近 2 度，防止瞬间甩动）
  if (current_mg996 < target_mg996) current_mg996 += 2;
  else if (current_mg996 > target_mg996) current_mg996 -= 2;

  if (current_sg90_1 < target_sg90_1) current_sg90_1 += 2;
  else if (current_sg90_1 > target_sg90_1) current_sg90_1 -= 2;

  if (current_sg90_2 < target_sg90_2) current_sg90_2 += 2;
  else if (current_sg90_2 > target_sg90_2) current_sg90_2 -= 2;

  // 7. 将最终角度输出给底层驱动
  Servo_SetAngle(&htim1, TIM_CHANNEL_1, current_mg996);
  Servo_SetAngle(&htim3, TIM_CHANNEL_3, current_sg90_1);
  Servo_SetAngle(&htim3, TIM_CHANNEL_4, current_sg90_2);
}

  // 启动舵机 PWM 对应的定时器通道
  HAL_TIM_PWM_Start(&htim1, TIM_CHANNEL_1);
  HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_3);
  HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_4);

  // 上电默认让舵机在 90 度中位
  Servo_SetAngle(&htim1, TIM_CHANNEL_1, 90);
  Servo_SetAngle(&htim3, TIM_CHANNEL_3, 90);
  Servo_SetAngle(&htim3, TIM_CHANNEL_4, 90);

```

## 队员：彭诗淇（硬件焊接与装配）

### 1. 前期硬件焊接与装配进度
 **模块焊接**：完成了 STM32 最小系统、电源模块、电机驱动、降压模块以及手柄接收模块的焊接与装配。
 **软硬联调**：在完成基础焊接后，配合团队完成了代码烧录与联合调试。
 **整体进度**：目前小车基本模块已焊接安装完毕，可实现手柄的完全控制。

### 2. 焊接踩坑与故障排查
在焊接实操中遇到了一些典型问题，通过排查均得到有效解决：
 **现象 1：引脚密集处容易连锡**。
 **解决**：使用助焊剂辅助，焊接时先固定元件引脚，焊后仔细检查并补焊。
 **现象 2：电机电源线焊点受力易松动**。
 **解决**：改用更粗的电源线，并在焊点处加套热缩管进行绝缘与物理固定。
 **现象 3：地线走线不合理，导致手柄偶发掉线**。
 **排查**：重新梳理地线回路，优化了走线布局，解决供电不稳问题。

### 3. 机械臂3D打印件处理
 **装配问题**：3D 打印件存在螺丝孔偏紧、关节处厚度不足的问题。强行装配易导致开裂，且会导致舵机运行不畅。
 **处理进度**：已单独对机械臂零件进行了扩孔处理。目前机械臂已自主完成建模与 3D 打印，但尚未安装至小车上。
